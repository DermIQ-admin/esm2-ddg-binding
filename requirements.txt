#
#   pip install -r requirements.txt

# --- PyTorch / CUDA -----------------------------------------------------------------
# The `+cu130` local version tag identifies the CUDA 13.0 build. It is NOT on PyPI, so
# the extra index below is required — without it pip resolves to the CPU-only wheel and
# training silently falls back to CPU.
#
# For a CPU-only install, delete the --extra-index-url line and use `torch==2.13.0`.
# For a different CUDA version, swap cu130 for your channel (cu128 / cu132) — see
# https://pytorch.org/get-started/locally/ and match it to your driver.
#
# torchvision and torchaudio are deliberately omitted: this project has no image or
# audio component, and they add ~1 GB plus a version-pinning constraint for nothing.

--extra-index-url https://download.pytorch.org/whl/cu130

torch==2.13.0+cu130
